# Introduction

WatchNLearn is an app that can be used to make note-taking with videos much simpler and easy-to-follow. The main features are a split-screen display, video-pausing when writing, and timestamps which can be associated with specific notes.

## Requirements

WatchNLearn and its associated packages all run on Python version 3.12.10, and require Python packages PyQT6, SQLAlchemy, and fastapi[standard]. The command to install these in terminal is:

`pip install "fastapi[standard]" PyQt6 SQLAlchemy`

# How to Run

Running WatchNLearn is very easy, simply open the folder's terminal and then run the file 'main.py' to open the app. Closing the app or your computer will still save your notes.
